# Товарная система (Product System)

Простая объектная модель для товаров, категорий и метрик с поддержкой наследования и логирования.

## Основные возможности

- **Абстрактный контракт**: `BaseProduct` задаёт обязательный интерфейс (`get_info`, `calculate_metric`).
- **Миксин логирования**: `LoggingMixin` выводит в консоль `[LOG]` при создании любого товара.
- **Инкапсуляция цены**: в `Product` цена защищена, изменение требует подтверждения при снижении.
- **Объединение товаров**: метод `new_product` ищет товар по имени (без учёта регистра) и обновляет количество/цену.
- **Наследование**: `Smartphone` и `LawnGrass` расширяют `Product` своими полями.
- **Категории и итерация**: `Category` хранит товары и поддерживает перебор через итератор.
- **Оператор сложения**: `__add__` позволяет складывать метрики товаров одного класса.
