# Интернет-магазин (базова структура)

## Описание
Проект представляет собой ядро для интернет-магазина

## Функциональность 
-**Класс Product** - описывает товар с атрибутами: название, описание, цена, количество.
-**Класс Category** - описывает категорию товаров с автоматическим подсчетом:
-общего количества категорий ('category_count')
-общего клдичества товаров во всех категориях ('product')

##Тестирование
